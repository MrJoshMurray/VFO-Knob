Install VFO-Knob on a Waveshare ESP32-S3 Knob Touch LCD 1.8 using your browser. No command line or ESP-IDF required.

!

Setup and custom images write the S3. Their image mode determines whether that means one app slot or the entire flash; they leave the second chip untouched. The Bluetooth installer below writes the second chip only.

01

Before connecting

Use a data-capable USB-C cable. Connect to the S3 port orientation.

  1. 01

    Use the plug orientation that exposes the ESP32-S3 USB serial port. If Windows shows USB-SERIAL CH340 (COM*), flip the plug: that orientation reaches the companion chip, not the S3.

  2. 02

    If VFO-Knob is already running over USB, its S3 serial port is available for about 6 seconds at boot before USB networking takes over. Hold a finger on the display through startup to keep the serial port available; otherwise Windows may show a network adapter instead of a COM port.

  3. 03

    Keep the knob powered and close other serial monitor tabs.

  4. 04

    After flashing, use a phone to join VFOKnob, set Wi-Fi, then choose your radio.

04

Install Bluetooth firmware

Install the official companion firmware directly to the second ESP32, verified before writing.

Flip the USB-C plug so the cable reaches the second chip's CH340 serial port. This writes its bootloader, partition table, OTA data, and Bluetooth firmware; the S3 is untouched and existing NVS settings are preserved.

Use desktop Chrome or Edge. The page checks for the knob's ESP32-U4WDH at revision 3 or later before writing. Windows may need the CH340 driver.
